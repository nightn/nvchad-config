# Neovim 快捷键用户指南（NvChad 配置）

> 本配置基于 [NvChad v2.5](https://github.com/NvChad/NvChad)，Leader 键为 **空格键（Space）**。
>
> 以下表格中，**来源** 列的含义：
> - 🟢 **NvChad** — NvChad 框架自带的默认快捷键
> - 🔵 **自定义** — 本仓库新增的快捷键
> - 🟠 **覆盖** — 本仓库对 NvChad 默认行为的修改/增强
> - 🔴 **已禁用** — NvChad 原有但被本仓库显式禁用的快捷键
>
> 模式缩写：`n` = 普通模式，`i` = 插入模式，`v` = 可视模式，`t` = 终端模式，`x` = 选择模式

## 1. 基础操作

| 快捷键 | 模式 | 功能 | 来源 |
|--------|------|------|------|
| `jk` | `i` | 退出插入模式（等同 `<Esc>`） | 🔵 自定义 |
| `;` | `n` | 进入命令模式（等同 `:`） | 🔵 自定义 |
| `<C-s>` | `n` `i` `v` | 保存文件 | 🟠 覆盖（NvChad 仅 `n` 模式） |
| `<C-c>` | `v` | 复制选中内容到系统剪贴板 | 🟠 覆盖（NvChad 为复制整个文件） |
| `<Esc>` | `n` | 清除搜索高亮 | 🟢 NvChad |

> 💡 **新手提示**：`jk` 是最常用的退出插入模式方式，比按 `Esc` 键更快捷。

## 3. 窗口管理

| 快捷键 | 模式 | 功能 | 来源 |
|--------|------|------|------|
| `<C-h>` | `n` `t` | 切换到左侧窗口 | 🟠 覆盖（增加了终端模式支持 + 自动切换 `nt→t`） |
| `<C-l>` | `n` `t` | 切换到右侧窗口 | 🟠 覆盖 |

> 💡 **说明**：NvChad 默认的窗口导航仅支持普通模式。本配置增强后，在终端窗口中也能使用 `<C-h/j/k/l>` 直接跳转到其他窗口，并自动从 Normal-Terminal（`nt`）模式切回 Terminal（`t`）模式。

## 4. Buffer（标签页）管理

| 快捷键 | 模式 | 功能 | 来源 |
|--------|------|------|------|
| `H` | `n` | 切换到上一个 buffer | 🔵 自定义 |
| `L` | `n` | 切换到下一个 buffer | 🔵 自定义 |
| `<leader>x` | `n` | 关闭当前 buffer | 🟢 NvChad |
| `<leader>b` | `n` | ~~新建空 buffer~~ | 🔴 已禁用 |

> 💡 **说明**：NvChad 默认用 `<Tab>` / `<S-Tab>` 切换 buffer，但这会影响 `<C-i>`（跳转列表前进）的功能，因此本配置禁用了它们，改用更直观的 `H` / `L`。

## 6. Telescope 搜索

Telescope 是 Neovim 最强大的模糊搜索框架。按下对应快捷键后，在弹出的浮动窗口中输入关键词即可搜索。

| 快捷键 | 模式 | 功能 | 来源 |
|--------|------|------|------|
| `<leader>ff` | `n` | 查找文件（按文件名） | 🟢 NvChad |
| `<leader>fa` | `n` | 查找所有文件（包括隐藏文件） | 🟢 NvChad |
| `<leader>fg` | `n` | 全文内容搜索（live grep，需要 ripgrep） | 🔵 自定义 |
| `<leader>fw` | `n` | 搜索工作区符号（LSP symbols） | 🟠 覆盖（NvChad 默认为 live grep） |
| `<leader>fb` | `n` | 查找已打开的 buffer | 🟢 NvChad |
| `<leader>fo` | `n` | 查找最近打开的文件 | 🟢 NvChad |
| `<leader>fh` | `n` | 搜索帮助文档 | 🟢 NvChad |
| `<leader>fz` | `n` | 在当前文件中模糊搜索 | 🟢 NvChad |
| `<leader>ma` | `n` | 查找标记（marks） | 🟢 NvChad |
| `<leader>cm` | `n` | 浏览 Git 提交记录 | 🟢 NvChad |
| `<leader>gt` | `n` | 跳转到定义（LSP definitions） | 🟠 覆盖（NvChad 默认为 git status） |
| `<leader>gr` | `n` | 跳转到引用（LSP references） | 🔵 自定义 |
| `<leader>ld` | `n` | 列出所有诊断信息（错误/警告） | 🔵 自定义 |
| `<leader>pt` | `n` | 选择隐藏的终端 | 🟢 NvChad |
| `<C-p>` | `n` | 搜索所有快捷键映射 | 🔵 自定义 |

**Telescope 窗口内操作：**

| 快捷键 | 功能 |
|--------|------|
| `<C-j>` / `<C-k>` | 上下移动选项 |
| `<CR>` | 确认选择 |
| `<C-x>` | 水平分屏打开 |
| `<C-v>` | 垂直分屏打开 |
| `<C-t>` | 在新标签页打开 |
| `<Esc>` | 关闭 Telescope |

## 7. LSP 代码智能

LSP（Language Server Protocol）提供了代码补全、跳转、重命名等智能功能。

| 快捷键 | 模式 | 功能 | 来源 |
|--------|------|------|------|
| `<leader>gt` | `n` | 跳转到定义（Telescope 展示） | 🟠 覆盖 |
| `<leader>gr` | `n` | 查看所有引用（Telescope 展示） | 🔵 自定义 |
| `<leader>rn` | `n` | 重命名符号（变量/函数名等） | 🟠 覆盖（NvChad 默认为 toggle relative number） |
| `<leader>fi` | `n` | 代码修复（Code Action） | 🔵 自定义 |
| `<leader>k` | `n` `v` | 智能悬浮：调试时求值 / 平时显示诊断信息 | 🔵 自定义 |
| `<leader>fw` | `n` | 搜索工作区符号 | 🟠 覆盖 |
| `<leader>nv` | `n` | 打开 Navbuddy（符号树导航） | 🔵 自定义 |
| `<leader>ds` | `n` | 诊断信息列表（loclist） | 🟢 NvChad |

> 💡 **`<leader>k` 的智能行为**：当 DAP 调试会话活跃时，该键会求值光标下的表达式或选中内容；否则会显示当前行的诊断浮窗。

### 12.5 调试期间的方向键（自动生效）

当调试会话启动后，方向键会自动绑定为调试操作；调试结束后自动恢复：

| 快捷键 | 功能 |
|--------|------|
| `<Down>` ↓ | 单步跳过（Step Over） |
| `<Right>` → | 单步进入（Step Into） |
| `<Up>` ↑ | 逆向单步跳过（rr Reverse Next） |
| `<Left>` ← | 逆向单步进入（rr Reverse Step） |

## 13. rr 逆向调试

[rr](https://rr-project.org/) 是 Linux 下的程序录制与回放调试工具，支持"倒退"执行。本配置支持在 Neovim 中进行 rr 逆向调试。

| 快捷键 | 模式 | 功能 | 来源 |
|--------|------|------|------|
| `<leader>rr` | `n` | 启动 rr 逆向调试会话 | 🔵 自定义 |
| `<leader>rc` | `n` | 逆向继续执行（Reverse Continue） | 🔵 自定义 |
| `<leader>rs` | `n` | 逆向单步进入（Reverse Step Into） | 🔵 自定义 |
| `<leader>rN` | `n` | 逆向单步跳过（Reverse Step Over） | 🔵 自定义 |

> ⚠️ **前提条件**：需要先使用 `rr record <program>` 录制程序运行，然后在 Neovim 中通过 `<leader>rr` 启动逆向调试会话。

## 附录 A：NvChad 快捷键速查表

**在 Neovim 中按 `<leader>ch` 即可查看完整的 NvChad 内置速查表。**

NvChad 提供的核心快捷键汇总（本配置未修改的部分）：

| 类别 | 快捷键 | 功能 |
|------|--------|------|
| 文件 | `<C-s>` | 保存文件 |
| 搜索 | `<leader>ff` | 查找文件 |
| 搜索 | `<leader>fo` | 最近打开的文件 |
| 搜索 | `<leader>fb` | 查找 buffer |
| 搜索 | `<leader>fh` | 搜索帮助 |
| 搜索 | `<leader>fz` | 当前文件内搜索 |
| 搜索 | `<leader>ma` | 查找标记 |
| 文件树 | `<C-n>` | 切换文件树 |
| 文件树 | `<leader>e` | 聚焦文件树 |
| Buffer | `<leader>x` | 关闭 buffer |
| 注释 | `<leader>/` | 切换注释 |
| 终端 | `<leader>h` | 新建水平终端 |
| 终端 | `<leader>v` | 新建垂直终端 |
| 终端 | `<A-i>` | 切换浮动终端 |
| 终端 | `<C-x>` | 退出终端模式 |
| 主题 | `<leader>th` | 切换主题 |
| 帮助 | `<leader>ch` | NvChad 速查表 |
| WhichKey | `<leader>wK` | 显示所有快捷键 |
| Git | `<leader>cm` | 浏览 Git 提交 |

## 附录 B：新手入门建议

### 快速开始

1. **打开文件**：`<leader>ff` 模糊搜索文件名
2. **全文搜索**：`<leader>fg` 在项目中搜索内容
3. **文件树**：`<C-n>` 打开侧栏文件树
4. **保存文件**：`<C-s>` 保存
5. **关闭 buffer**：`<leader>x` 关闭当前文件

### 代码导航

1. **跳转到定义**：`<leader>gt`
2. **查看引用**：`<leader>gr`
3. **重命名**：`<leader>rn`
4. **代码修复**：`<leader>fi`
5. **符号导航**：`<leader>nv` 打开 Navbuddy

### 常用操作

1. **退出插入模式**：`jk`（比 `Esc` 更快）
2. **注释代码**：`<leader>/`
3. **格式化代码**：`<leader>fm`
4. **打开终端**：`` <C-`> `` 或 `<A-j>`
5. **切换 buffer**：`H`（上一个）/ `L`（下一个）

### 调试入门

1. 在代码行上按 `<leader>bb` 设置断点
2. 按 `<F5>` 或 `<leader>dc` 启动调试
3. 使用 `<F10>`（跳过）/ `<F11>`（进入）/ `<F12>`（跳出）控制执行
4. 按 `<leader>k` 查看变量值
5. 按 `<leader>dq` 终止调试

### 查找快捷键

- 按 `<C-p>` 搜索所有快捷键映射
- 按 `<leader>wK` 显示 WhichKey 所有快捷键
- 按 `<leader>ch` 打开 NvChad 速查表

> 📝 **记住**：Leader 键是**空格键**。所有以 `<leader>` 开头的快捷键，都是先按空格，再按后续按键。
